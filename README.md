# Лабораторная работа №4 по python

Реализованы: алгоритм для составления чисел фибоначи, insert sort, heap sort, radix sort, а также бенчмарк для сравнения, стек


## 1 Запуск и использование CLI

```bash
# Интерактивное меню
uv run algo

# Отдельные подкоманды CLI
uv run algo fib 10
uv run algo sort --algo all --dataset random --size 20 --key abs
uv run algo stack A B C
uv run algo gen --type nearly_sorted --size 15
uv run algo bench --repeats 5 --sizes 100 1000 10000 --workers 4
uv run algo test all

# Запуск автотестов
uv run pytest
```

## 3. Анализ результатов бенчмарка

- **`insertion_sort`**:
  - На наборе `sorted` имеет линейную сложность $O(n)$, так как внутренний цикл заканчивается после первого же сравнения (все элементы уже упорядочены). Алгоритм быстрее остальных сортировок на упорядоченных данных: 0.15 с на $10^6$, 1.56 с на $10^7$ и 14.20 с на $10^8$ (время растёт строго пропорционально размеру в 10 раз).
  - На остальных наборах проявляется квадратичная сложность $O(n^2)$. Уже при $N = 1\ 000\ 000$ время выполнения превышает отсечку 100 с (`N/A (>100s, O(n²))`).

- **`heap_sort`**:
  - Сложность всегда $O(n \log n)$. При росте $N$ в 10 раз (с $10^6$ до $10^7$) время увеличивается примерно в ~12–13 раз (с 5.03–8.78 с до 59.41–85.89 с), что полностью соответствует теоретической оценке сложности алгоритма ($\frac{10^7 \log_2 10^7}{10^6 \log_2 10^6} \approx 11.6$).
  - Из-за частых промахов кэша процессора при переходе по узлам кучи не укладывается в 100 с на `random` уже при $N = 10^7$, а также ни на одном наборе при $N = 10^8$.

- **`radix_sort`**:
  - Алгоритм со сложностью $O(d \cdot (n + k))$. На $1\ 000\ 000$ элементов сортирует за 0.17–1.21 с, значительно опережая `heap_sort`.
  - Единственный алгоритм, который уложился в 100 с на массивах из $100\ 000\ 000$ элементов: `duplicates` (13.92 с), `sorted` (60.43 с) и `reversed` (60.89 с). На `duplicates` показывает наилучшее время за счёт хорошей локальности данных в кэше. Алгоритм не сравнивает элементы между собой, а распределяет их по разрядам.
